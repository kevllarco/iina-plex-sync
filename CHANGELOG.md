# Changelog

## 1.0.0

First public release.

- Plex PIN sign-in, server picker, Keychain-first token storage
- File-based library matching (basename + path tail + size); no title search
- Timeline progress + watched at configurable threshold (default 90%)
- Sticky HUD with drag / corner snap; position remembered
- **⌃⇧S** pause/resume sync; **⌃⇧P** show/hide HUD (also Plugin menu + Preferences)
